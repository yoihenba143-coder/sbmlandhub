# SBM LAND HUB - Local Images Directory

Place the following image files here (`public/image/`):

1. **`hero.jpg`** - High-resolution landscape banner for the Hero section.
2. **`land.jpg`** - Image for Land / Plots category & featured land listing.
3. **`house.jpg`** - Image for Residential House / Home category & featured house listing.
4. **`field.jpg`** - Image for Agricultural Field / Farmland category.
5. **`shop.jpg`** - Image for Commercial Shop / Retail space category & featured shop listing.

All images are served in Next.js from `/image/<filename>`.
